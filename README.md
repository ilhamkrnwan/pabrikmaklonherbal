# pabrikmaklonherbal

Platform web pemasaran terpadu dan katalog B2B jasa manufaktur/maklon obat tradisional dan suplemen herbal (CV Al Afiat Sehat Alami) berstandar CPOTB dan BPOM RI.

## Arsitektur & Komponen
- **Plugin Kustom**: `wp-content/plugins/alafiat-maklon-core` (CPT `produk_maklon`, patterns, kalkulator simulasi jalur & biaya maklon)
- **Tema Kustom**: `wp-content/themes/alafiat-maklon-theme` (Gutenberg FSE Block Theme)
- **Dokumentasi & ADR**: `docs/` & `GLOSSARY.md`
